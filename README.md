# От сказочной героини к современной профессии

Профориентационное веб-приложение для школьников на Next.js.

## Запуск

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS
- lucide-react
- Данные в TypeScript-файлах, результат теста в localStorage

## Маршруты

- `/` — главная
- `/test` — тест
- `/result` — результат
- `/professions` — каталог профессий
- `/professions/[slug]` — профессия
- `/heroines` — героини
- `/heroines/[slug]` — героиня
- `/about` — о проекте
